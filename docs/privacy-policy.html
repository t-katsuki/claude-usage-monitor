Privacy Policy — Claude Usage Monitor

Last updated / 最終更新: 2026-05-23

What data does this extension collect?

This extension collects no data. Your subscription information stays entirely on your device.

  • The extension reads your subscription status and usage quotas directly from your authenticated session with claude.ai using your existing browser cookies.
  • The retrieved data is displayed in the extension's popup.
  • The data is not stored, not transmitted to any external server, and not shared with any third party.

What permissions does this extension use?

The extension requests a single host permission: https://claude.ai/*

This permission allows the extension to make authenticated requests to claude.ai's API endpoints (using your existing browser session) to retrieve:

  • Your organization information, to identify your Claude.ai subscription.
  • Your current usage quotas: the 5-hour limit utilization, the weekly limit utilization, and their respective reset times.

The extension does not access any other websites and does not perform any other action on claude.ai beyond reading this usage information.

How is data handled?

  • All data fetching happens locally in your browser via the standard browser fetch API.
  • Data is rendered only in the extension popup UI.
  • When you close the popup, the data is discarded from memory.
  • No data is persisted between popup sessions.
  • No data leaves your device.

Third-party services

This extension does not use any third-party services, analytics, advertising, or tracking.

この拡張機能が収集するデータ

この拡張機能はデータを一切収集しません。サブスクリプション情報は、あなたのデバイス内で完結します。

  • 拡張機能は、あなたが claude.ai にログイン中のブラウザセッション(Cookie)を使って、サブスクリプション状態と利用枠情報を直接読み取ります。
  • 取得したデータは、拡張機能のポップアップ内で表示されます。
  • データは保存されず、外部サーバーに送信されず、第三者と共有されません。

使用する権限

この拡張機能は、https://claude.ai/* というホスト権限を 1 つだけ要求します。

この権限により、拡張機能はあなたの既存のブラウザセッションを使って claude.ai の API エンドポイントに認証済みリクエストを行い、以下の情報を取得します:

  • あなたが所属する組織情報(Claude.ai サブスクリプションを識別するため)
  • 現在の利用枠: 5 時間制限の使用率、週間制限の使用率、それぞれのリセット時刻

この拡張機能は、他のウェブサイトにはアクセスせず、また claude.ai 上でこの利用枠情報の読み取り以外の動作は一切行いません。

データの取り扱い

  • データの取得は、ブラウザ標準の fetch API を使ってローカルで行われます。
  • データは拡張機能のポップアップ UI 内でのみ表示されます。
  • ポップアップを閉じると、データはメモリから破棄されます。
  • ポップアップを開くたびに新しくデータを取得します(永続化なし)。
  • データはデバイスから外に出ません。

第三者サービス

この拡張機能は、第三者サービス、アナリティクス、広告、トラッキングのいずれも使用しません。
